# Changelog

## 2.0.0-foundation

### Added
- New visual-first homepage with a clearer value proposition and learning path.
- New curriculum dashboard with reusable module cards.
- Reusable `ButtonLink` and `ModuleCard` UI components.
- New chemistry-inspired hero visual built without external image dependencies.

### Improved
- Typography now uses the configured Geist font throughout the site.
- Stronger responsive spacing and mobile layouts.
- Clearer calls to action and lesson discovery.
- More consistent emerald, slate, blue, violet, and amber visual language.

### Notes
- Existing lesson routes and content remain compatible.
- This release is the first foundation step, not an MDX migration.
