ORGANIC CHEMISTRY HUB — LEWIS STRUCTURE BUILDER

1. Stop the development server with Ctrl+C.
2. Copy app, components, and docs into the project root.
3. Allow Windows to merge folders and replace matching files.
4. Remove the Next.js cache:
   Remove-Item -Recurse -Force .next
5. Start with Webpack:
   cmd /c npx next dev --webpack
6. Test:
   http://localhost:3000/calculators/lewis-structure-builder
   http://localhost:3000/calculators
7. Stop the server and run:
   cmd /c npm run build
8. Commit after the build passes:
   git add .
   git commit -m "feat(interactive): add Lewis structure builder"
   git push origin main
