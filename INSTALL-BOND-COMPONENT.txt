ORGANIC CHEMISTRY HUB - BOND COMPONENT

1. Stop the development server.
2. Copy the app, components, and docs folders into the project root.
3. Allow Windows to merge folders.
4. Run:

   Remove-Item -Recurse -Force .next
   cmd /c npm run build
   cmd /c npx next dev --webpack

5. Open:

   http://localhost:3000/lab/bond-playground

6. Commit:

   git add .
   git commit -m "feat(chemistry): add reusable bond component"
   git push origin main
