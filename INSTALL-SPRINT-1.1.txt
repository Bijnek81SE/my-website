INSTALLATION
1. Stop the development server with Ctrl+C.
2. Copy the included app, components, and docs folders into the project root.
3. Copy CHANGELOG.md into the project root.
4. Allow Windows to merge folders and replace matching files.
5. Run: cmd /c npm run dev
6. Check http://localhost:3000 and http://localhost:3000/learn
7. Run: cmd /c npm run build

GIT CHECKPOINT
After testing:

  git commit -m "refactor(ui): add design system foundation"
