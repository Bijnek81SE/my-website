# Organic Chemistry Hub v2.0.0 Baseline

This baseline consolidates the latest project state with all completed features.

## Included

- Design-system components in `components/ui`
- Reusable lesson framework in `components/Lesson`
- MDX support and Atomic Structure MDX pilot
- Central lesson registry
- Chemistry graphics primitives
- Interactive carboxylate resonance diagram
- Lewis Structure Builder
- Lab framework
- Functional Group Quick Check
- Foundation lessons: Organic Chemistry, Atomic Structure, Chemical Bonding, Hybridization, Lewis Structures, Formal Charge, and Resonance
- Homepage, curriculum, calculators, resources, and reference pages
- Project documentation
