MOLECULAR POLARITY EXPLORER

1. Stop the development server.
2. Copy the app, components, and docs folders into the project root.
3. Allow Windows to merge folders and replace matching files.
4. Run:

   Remove-Item -Recurse -Force .next
   cmd /c npm run build
   cmd /c npx next dev --webpack

5. Test:

   http://localhost:3000/lab
   http://localhost:3000/lab/molecular-polarity

6. Commit:

   git add .
   git commit -m "feat(lab): add molecular polarity explorer"
   git push origin main
