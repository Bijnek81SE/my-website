# Organic Chemistry Hub Design System

## Principles
1. Visuals must teach, not decorate.
2. Chemistry notation must remain accurate at every screen size.
3. Use emerald for primary actions, slate for structure, and blue/violet/amber as supporting scientific accents.
4. Prefer reusable components over repeated Tailwind class strings.
5. Every page must remain usable with reduced motion enabled.

## Illustration rules
- Electron arrows begin at an electron pair or bond and end at the receiving atom or bond.
- Resonance arrows and reaction arrows must never be used interchangeably.
- Atom labels, formal charges, and partial charges must remain legible on mobile.
- SVG diagrams should include descriptive captions in the lesson content.
