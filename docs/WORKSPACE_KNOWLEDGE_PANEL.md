# Workspace Knowledge Panel

The Workspace overview now acts as a molecule-specific learning hub instead of exposing unlabeled generic reference buttons.

For every published Workspace molecule, the panel provides:

- a clearly identified functional-group reference;
- curated reagent references with an explanation of why each reagent matters;
- relevant interactive labs;
- reaction pathways to compare in the Reaction Explorer;
- prerequisite or reinforcing lessons.

## Design principles

1. **Every link explains its context.** Students should understand why a destination is relevant before opening it.
2. **No random primary reagent.** Reagents appear as a labeled collection, not as an unexplained second reference button.
3. **Only published routes are linked.** The panel does not create dead links to planned reference entries.
4. **Knowledge belongs to the registry.** Adding a future Workspace molecule requires data changes, not custom UI branches.
5. **The panel remains synchronized.** Switching the active molecule immediately replaces every knowledge connection.

Initial coverage includes Ethanol, Acetone, Ethyl acetate, Toluene, Propene, and 2-Bromopropane.
