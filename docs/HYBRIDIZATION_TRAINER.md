# Hybridization Trainer

Route: `/lab/hybridization`

The trainer uses the shared lab framework and provides:

- foundation, intermediate, and mixed exercise pools;
- immediate answer feedback;
- electron-domain, geometry, and bonding explanations;
- simplified orbital previews;
- score and progress tracking;
- links back to the Hybridization lesson.

The exercise data lives in `components/lab/HybridizationTrainer.tsx` and can be extended without changing the page layout.
