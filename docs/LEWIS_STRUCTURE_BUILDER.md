# Lewis Structure Builder

The first interactive practice tool in Organic Chemistry Hub.

## Current scope

The builder supports three guided molecules:

- H2O
- NH3
- CO2

Students can:

- cycle bond orders by clicking a bond,
- select an atom,
- add or remove lone pairs,
- monitor the total valence-electron count,
- check duet and octet completion,
- view formal charges,
- request a concise hint.

## Pedagogical constraints

This first version deliberately uses fixed atom positions. It teaches electron accounting and bond-order decisions without introducing drag-and-drop complexity.

The completion check uses known target structures for the supported molecules. Future versions can add ions, resonance structures, alternative valid contributors, and a more general graph-based validator.

## Accessibility

Atoms and bonds are keyboard-selectable in the SVG. All controls use native buttons and status information is also presented as text outside the diagram.
