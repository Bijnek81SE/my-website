# Molecular Geometry Trainer

Route: `/lab/molecular-geometry`

## Included

- Foundation, Intermediate, and All modes
- 12 molecule exercises
- Seven molecular geometry answer types
- Responsive SVG geometry models
- Immediate scoring, hints, explanations, bond angles, and hybridization
- Lab landing-page entry

## Reused framework

The trainer uses the existing `ExerciseCard`, `FeedbackPanel`, `HintPanel`, `ProgressBar`, `ScoreBadge`, `ChallengeFooter`, and `LabShell` components.
