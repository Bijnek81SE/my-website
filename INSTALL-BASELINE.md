# Install the v2.0.0 baseline

1. Keep your current project as a backup.
2. Extract this ZIP into a new folder.
3. Open PowerShell in the folder containing `package.json`.
4. Run `cmd /c npm install`.
5. Run `cmd /c npx next dev --webpack`.
6. Test `/`, `/learn`, `/lab`, and `/calculators/lewis-structure-builder`.
7. Stop the server and run `cmd /c npm run build`.
8. Only after the build succeeds, connect or copy your `.git` folder and commit the baseline.
