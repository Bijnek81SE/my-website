# Canonical Reagent Registry Manifest

## Milestone

Unified Chemistry Content & Extension Architecture — Phase 5

## Added

- Typed canonical reagent entities
- One record per published reagent
- Indexed ID, slug, name, and alias lookup
- Relationship and capability selectors
- Cross-registry validation
- Generated reagent route coverage
- Canonical search, sitemap, knowledge-graph, and Workspace integration

## Canonical records

- Hydroxide
- Sulfuric acid
- Bromine
- Hydrogen with palladium
- Borane / peroxide workup
- HBr with peroxide

## Architectural outcome

A new reagent is added through one reagent record and one registry import. Public reference pages and repeated platform integrations derive from that registry rather than maintaining separate reagent lists.
